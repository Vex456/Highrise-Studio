## Features

1. **Interactive 2.5D / 3D Virtual Room Radar**:
   - Real-time isometric floor grid mapping live player & bot `(x, y, z)` coordinates.
   - Overhead speech bubbles floating above speaking avatars.
   - Tap-to-target player moderation sheet (`!tele`, `!summon`, `!kick`, `!ban`, `!mod`, `!designer`).
2. **Fleet Matrix Management**:
   - Live telemetry for all 6 bots (Greeter, Guardian, Jukebox, GameHost, Chaty, Inspector).
   - CPU %, Memory MB, and bot latency pings.
   - Mass commands: `!come all`, `!base all`, `!fitall`, `!dance all`.
3. **Radio Jukebox & In-Ear Streaming**:
   - Rotating vinyl player with live progress scrubber.
   - Queue management with YouTube / stream URL addition.
   - **"Listen on Device"** mode: stream the bot radio stream directly through phone speakers/headphones.
4. **Interactive Mini-Games & Chaty Matchmaker**:
   - Police & Thief real-time state and round triggers.
   - Word Chain (Shiritori) target letter tracking.
   - Chaty 1-on-1 anonymous blind matchmaking in private rooms.
5. **Modern Interactive Config & Live Console**:
   - Enable/disable toggle switches for each bot and room.
   - Color-coded live streaming logs with filter chips.
   - Soft restart & container reboot safeguards.
6. **Automated Cloud APK Build**:
   - Every push triggers the GitHub Actions workflow to build `app-release.apk` automatically!

## How to Get the APK

1. Go to the **[Actions tab](https://github.com/Vex456/Highrise-Studio/actions)** in this repository.
2. Click on the latest **Build Android APK** run.
3. Download the **`Highrise-Studio-Release-APK`** artifact zip at the bottom of the page.
4. Extract and install the `.apk` on your Android phone!
